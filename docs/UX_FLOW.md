# Gym Notepad — экраны и навигация MVP

## 1. Принципы мобильного интерфейса

- Основной сценарий выполняется одной рукой.
- Во время тренировки пользователь остаётся на одном вертикально прокручиваемом экране.
- Вес и повторения доступны без открытия диалогов.
- Последнее значение можно повторить одним касанием.
- Ошибки показываются рядом с подходом, а не только при завершении тренировки.
- Таймер виден, но не блокирует ввод.
- Все изменения сохраняются сразу.
- Рекомендации всегда объясняются и требуют подтверждения.

## 2. Карта навигации

```text
Главная
├─ Начать тренировку
│  ├─ Выбрать шаблон
│  ├─ Скопировать прошлую
│  └─ Пустая тренировка
│       └─ Активная тренировка
│           ├─ Выбрать/создать упражнение
│           ├─ История упражнения
│           ├─ Изменить порядок
│           └─ Завершить
│               └─ Проверка данных
│                   └─ Итоги и рекомендации
├─ Продолжить активную тренировку
├─ История
│  ├─ Просмотр тренировки
│  └─ История упражнения
├─ Шаблоны
│  ├─ Создать шаблон
│  └─ Редактировать шаблон
├─ Вес тела
└─ Настройки
   ├─ Единицы
   ├─ Таймер и уведомления
   └─ Резервная копия
```

Нижняя навигация доступна вне активной тренировки:

- Главная;
- История;
- Шаблоны;
- Настройки.

Активная тренировка открывается отдельным полноэкранным потоком. Системная кнопка «Назад» не завершает тренировку и не удаляет данные.

## 3. Главная

### Состояние без активной тренировки

- основная кнопка `Начать тренировку`;
- карточка последней тренировки;
- ближайшая рекомендация или последнее достижение;
- быстрый переход к записи веса тела.

### Состояние с активной тренировкой

- крупная карточка `Продолжить тренировку`;
- прошедшее время;
- количество выполненных подходов;
- активный таймер отдыха;
- вторичная кнопка начала новой тренировки недоступна до завершения или удаления текущей.

## 4. Выбор способа старта

Три крупные карточки:

1. `Из шаблона` — список A/B/C и пользовательских шаблонов.
2. `Повторить прошлую` — последние тренировки с датой и упражнениями.
3. `Пустая тренировка` — создаётся активная сессия без упражнений.

До создания сессии пользователь может изменить название и записать актуальный вес тела.

## 5. Активная тренировка

### Верхняя панель

- название тренировки;
- длительность;
- меню действий;
- кнопка `Завершить`.

### Карточка упражнения

- порядковый номер и название;
- тип нагрузки;
- рекомендация с коротким объяснением;
- история прошлого выполнения;
- заметка;
- признаки `Боль` и `Техника`;
- список подходов.

### Строка подхода

```text
№ | тип | вес | повторения | усилие | выполнено
```

- Для разминочных подходов оценка усилия скрыта.
- Поле веса сразу показывает единицу.
- Кнопка повтора предыдущего веса появляется при пустом поле.
- Для гравитрона подпись меняется на `Помощь`.
- Для собственного веса поле внешней нагрузки скрывается или называется `Доп. вес`.
- Выполненный подход можно исправить без удаления.

### Быстрая оценка усилия

- `2+`;
- `1`;
- `Отказ`;
- повторное касание снимает выбор.

Отсутствие выбора означает `UNKNOWN`.

### Таймер

После завершения подхода появляется компактная панель:

```text
Отдых 01:42     -30     +30     Пропустить
```

Панель закреплена в нижней части экрана, но не перекрывает активный подход.

## 6. Выбор упражнения

- поиск по каноническим и альтернативным названиям;
- недавно использованные упражнения;
- создание нового упражнения;
- выбор типа нагрузки;
- шаг веса;
- единица шага;
- оборудование или название тренажёра.

При замене упражнения пользователь выбирает:

- заменить только в текущей тренировке;
- также предложить изменение шаблона после завершения.

## 7. Проверка перед завершением

Экран появляется только при наличии проблем:

- вес без повторений;
- повторения без обязательного веса;
- запланированный, но не выполненный подход;
- активный таймер;
- незавершённое упражнение.

Для каждого пункта доступны действия `Исправить`, `Пропустить` или `Оставить неполным`.

## 8. Итоги тренировки

- длительность и список упражнений;
- изменения относительно прошлого выполнения;
- лучший рабочий вес;
- прибавка повторений при том же весе;
- серия успешных тренировок;
- рекомендации на следующий раз;
- поле заметки для планирования следующей тренировки.

Каждая рекомендация имеет:

- предложение;
- использованные прошлые результаты;
- причину;
- действия `Принять`, `Изменить`, `Не использовать`.

## 9. История упражнения

Основной режим — таблица тренировок:

```text
Дата | вес | повторения по подходам | усилие | результат
```

Переключатели:

- рабочий вес;
- повторения при одинаковом весе;
- лучшие подходы.

График является дополнительным представлением и не заменяет исходные подходы.

## 10. Шаблоны

Редактор шаблона позволяет:

- изменить название и описание;
- менять порядок упражнений перетаскиванием;
- задать разминки и рабочие подходы;
- задать диапазон повторений;
- настроить отдых и шаг веса;
- добавить пояснение и ссылки;
- архивировать шаблон.

## 11. Настройки

- единица массы: кг или фунты;
- таймер включён/выключен;
- автоматический запуск таймера;
- отдых по умолчанию;
- разрешение уведомлений;
- экспорт резервной копии;
- восстановление резервной копии;
- информация о локальном хранении данных.

## 12. Состояния и ошибки

- При ошибке сохранения введённые значения остаются на экране.
- Потеря сети не показывается как ошибка в локальном MVP.
- При восстановлении после перезапуска открывается активная тренировка.
- Если уведомления запрещены, таймер продолжает работать внутри приложения и предлагает открыть системные настройки.
- Недоступная рекомендация объясняется конкретной причиной: недостаточно истории, неизвестный шаг веса, неполные подходы или отметка боли.

## 13. Первый реализуемый вертикальный сценарий

1. Главная.
2. Старт из демонстрационного шаблона.
3. Активная тренировка с одним упражнением и тремя подходами.
4. Ввод веса, повторений и усилия.
5. Завершение.
6. Итог с результатом алгоритма прогрессии.

Этот сценарий проверяет ключевую ценность продукта до реализации полного редактора шаблонов и аналитики.
