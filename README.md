# Gym Notepad

Android-приложение для записи силовых тренировок непосредственно в зале. Проект развивается как offline-first дневник с шаблонами, быстрым вводом подходов и объяснимыми рекомендациями по прогрессии.

## Текущее состояние

Создан рабочий вертикальный срез Android-прототипа:

- Kotlin и Jetpack Compose;
- навигация между основными экранами;
- локальная база Room без обязательного аккаунта и интернета;
- создание и восстановление незавершённой тренировки;
- добавление и замена упражнений непосредственно в активной тренировке;
- удаление и изменение порядка упражнений в активной тренировке;
- добавление и удаление последних подходов;
- предупреждение перед завершением пустой тренировки или тренировки с незаполненными подходами;
- опциональный таймер отдыха с ручным запуском, паузой, сбросом и настройкой по 30 секунд;
- необязательный автозапуск таймера после сохранения подхода;
- локальный учёт веса тела с быстрым вводом на главном экране;
- сравнение веса с предыдущим измерением и список пяти последних значений;
- удаление последнего измерения с подтверждением;
- график последних измерений веса тела;
- графики прогресса упражнений по рабочему весу и повторениям с переключением метрики;
- специальная подпись графика помощи для гравитрона, где уменьшение значения означает прогресс;
- постоянные настройки единиц веса: килограммы или фунты;
- настройки длительности и автозапуска таймера отдыха;
- экспорт полной локальной резервной копии в JSON через системный выбор файла;
- атомарное восстановление тренировок, шаблонов, упражнений, веса тела и настроек из копии;
- запись веса, повторений и усилия каждого подхода;
- завершение активной тренировки;
- повтор последней завершённой тренировки с сохранением рабочих весов;
- локальный каталог упражнений с шестью типами нагрузки;
- создание шаблонов и настройка подходов и диапазона повторений;
- запуск тренировки из сохранённого шаблона;
- история завершённых тренировок с фактическими подходами;
- сравнение рабочего веса с предыдущим выполнением;
- сравнение повторений при одинаковом весе;
- корректная трактовка уменьшения помощи в гравитроне как прогресса;
- итоговый экран после завершения тренировки;
- объяснимые рекомендации: повторить вес, добавить повторения, перейти к следующему весу или рассмотреть снижение;
- отдельные схемы нагрузки для гантелей, плиточных тренажёров, штанги и тренажёров под блины;
- расчёт следующего доступного веса и раскладки блинов на одну сторону;
- чистая доменная логика прогрессии с модульными тестами;
- инструментальные тесты полного цикла локального репозитория и редактирования активной тренировки.

При первом запуске создаётся стартовый шаблон, который можно расширять упражнениями из каталога.

## Требования для сборки

- актуальный Android Studio с поддержкой Android Gradle Plugin 9.5;
- JDK 17;
- Android SDK 37;
- интернет при первой синхронизации зависимостей.

Открыть корневую папку проекта в Android Studio и выполнить Gradle Sync.
